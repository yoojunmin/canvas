# 모여그림 — 멀티 캔버스 게임

친구들과 링크를 공유하고 같은 캔버스에 실시간으로 함께 그리는 웹 앱입니다. Node.js, Express, Socket.IO로 만들었고 Render에 바로 배포할 수 있습니다.

## 기능

- 여러 개의 이름 있는 캔버스를 만들고 오가며 그림 그리기
- 브러시, 지우개, 페인트통, 스포이드 도구
- 브러시 크기 조절과 HEX 및 RGB 색상 입력
- 마우스와 모바일 터치 입력
- 같은 캔버스에 접속한 사람의 선과 페인트 채우기를 실시간 공유
- 캔버스별 현재 참여 인원과 초대 링크

## 로컬 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`을 여세요. 다른 기기에서도 접속하려면 같은 네트워크에서 실행 중인 컴퓨터의 IP와 포트 3000을 사용하면 됩니다.

## GitHub와 Render 배포

1. 이 폴더를 GitHub 저장소에 올립니다.
2. Render에서 **New + → Blueprint**를 선택하고 저장소를 연결합니다.
3. Render가 `render.yaml`을 읽어 Node 웹 서비스를 만들면 배포가 완료됩니다.
4. 생성된 `onrender.com` 주소를 열고 **초대 링크**를 복사해 친구에게 공유합니다.

또는 Render에서 **New + → Web Service**로 저장소를 연결하고 Build Command에 `npm install`, Start Command에 `npm start`를 입력해도 됩니다.

## 저장 방식

캔버스 이름과 그림 기록은 현재 Node 서버 메모리에 보관됩니다. 같은 서버에 접속한 사람끼리는 공유되며, 서버가 재시작되면 캔버스 목록과 기록이 초기화됩니다. 영구 저장이 필요해지면 PostgreSQL과 이미지/스냅샷 저장소를 연결하면 됩니다. 현재 버전은 Render 단일 웹 서비스에서 동작하도록 구성되어 있습니다.
